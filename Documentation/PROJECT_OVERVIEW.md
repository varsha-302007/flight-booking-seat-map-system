# Flight Booking and Seat Map System

## Project Overview

The Flight Booking and Seat Map System is a web-based application
that allows users to search for flights, view flight details,
select seats, book tickets, and manage their bookings.

The system also includes an admin dashboard for managing flight
information.

## Technologies Used

- C++ – Backend logic and object-oriented programming
- React – Frontend user interface
- Node.js – API bridge connecting the frontend and C++ backend
- File Handling – Storing application data
